# Guardian Pro - Security Auditor

## Overview
Guardian Pro is a Windows security auditing tool with a graphical interface.

It analyzes system configurations to detect potential security risks and allows basic remediation actions.

## Features
- Firewall status check
- Antivirus status verification
- RDP (port 3389) detection
- File scan for sensitive keywords
- Automated system repair options
- PDF report generation

## Technologies Used
- Python
- CustomTkinter (GUI)
- PowerShell commands
- Socket (port scanning)
- FPDF (report generation)

## How it works
The tool performs a series of system checks:
1. Verifies if the firewall is enabled
2. Checks antivirus real-time protection
3. Detects if RDP port is open
4. Scans files for sensitive keywords
5. Generates a security score

## Notes
This project is intended for educational purposes and basic security awareness.
